# Contributing

Thanks for considering a contribution.

This repository is part of the [THOX.ai](https://thox.ai) portfolio. The
canonical contribution guide for the whole portfolio lives at
[ttracx/thox-meta](https://github.com/ttracx/thox-meta/blob/main/CONTRIBUTING.md).

Read that first. It covers:

- Code of Conduct ([Contributor Covenant 2.1](CODE_OF_CONDUCT.md))
- Branch naming and Conventional Commits
- DCO sign-off requirement
- Coding standards (Rust, Python, TypeScript, Swift)
- ADR process for architectural changes
- Release and versioning policy

## Repo-specific notes

See the [README](README.md) for build, test, and lint commands for this
particular repo. If a command in the canonical guide does not match what
this repo uses, the README wins for that command.

## Reporting issues

Use the issue templates under
[`.github/ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE/). For security
vulnerabilities follow [`SECURITY.md`](SECURITY.md) instead of opening a
public issue.
