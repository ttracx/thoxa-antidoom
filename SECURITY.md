# Security Policy

This repository inherits the THOX.ai portfolio security policy.

The canonical policy lives at
[ttracx/thox-meta SECURITY.md](https://github.com/ttracx/thox-meta/blob/main/SECURITY.md).

## Reporting a vulnerability

**Do not open public GitHub issues for security vulnerabilities.**

Email **security@thox.ai** with the details. You will receive an
acknowledgement within two business days.

A good report includes:

- Affected repository and version (commit SHA or release tag)
- Description of the vulnerability and attacker model
- Reproduction steps or proof of concept
- Expected security guarantee that is violated
- Known mitigations or workarounds
- Your preferred name and contact for credit

## Supported versions

This repo follows the default THOX support policy from the canonical doc
unless the README declares otherwise:

| Version          | Security fixes |
|------------------|----------------|
| Latest minor     | Yes            |
| Previous minor   | Critical only  |
| Older            | No             |

Pre-1.0 releases may only support the latest tag.

## Disclosure

Default disclosure window: 90 days from acknowledgement. See the
[canonical SECURITY.md](https://github.com/ttracx/thox-meta/blob/main/SECURITY.md)
for the full process, severity classification, CVE handling, scope, and
safe harbor terms.
